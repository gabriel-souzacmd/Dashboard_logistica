## Sobre o Projeto

O **Logistics Analytics** é um Dashboard Analítico de SLA (Service Level Agreement) e Performance Logística. Ele foi desenvolvido com o objetivo de fornecer uma visão clara e em tempo real dos principais indicadores de uma operação de transportes e entregas. 

Este projeto simula um ambiente de acompanhamento logístico, ideal para gerentes e analistas de supply chain que precisam monitorar volumes de entrega, taxa de sucesso no prazo e status das remessas.

## Funcionalidades

- **Métricas Chave (KPIs):** Acompanhamento rápido do Total de Entregas, Taxa de SLA (No Prazo), Tempo Médio de Entrega (TME) e Pedidos em Atraso.
- **Gráfico de SLA:** Visualização da evolução diária da aderência aos prazos utilizando gráfico de linha interativo.
- **Gráfico de Regiões:** Comparativo de volume de entregas por região através de gráfico de barras.
- **Tabela de Operações Dinâmica:** Listagem das últimas remessas com identificadores visuais (badges) para diferentes status (Entregue, Em Trânsito, Atrasado).
- **Interface Responsiva:** Design que se adapta perfeitamente a diferentes tamanhos de tela (desktop, tablets e smartphones).

## Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes ferramentas:

- **HTML5:** Estruturação semântica da página.
- **Tailwind CSS (via CDN):** Estilização rápida, moderna e responsiva.
- **JavaScript (Vanilla):** Lógica para renderização de dados simulados e manipulação do DOM.
- **Chart.js (via CDN):** Biblioteca para criação de gráficos dinâmicos e interativos.
- **Phosphor Icons:** Pacote de ícones profissionais e minimalistas.

## Como Executar o Projeto

Como o projeto é construído unicamente com tecnologias Front-end (HTML/CSS/JS), executá-lo é muito simples.

### Opção 1: Execução Local (Testes e Desenvolvimento)
1. Clone este repositório ou baixe o arquivo `.html`.
2. Abra a pasta do projeto no **VS Code**.
3. Utilize a extensão **Live Server** clicando com o botão direito no arquivo `index.html` e selecionando "Open with Live Server".
4. O dashboard abrirá automaticamente no seu navegador padrão.
